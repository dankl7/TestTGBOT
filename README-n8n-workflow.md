# N8N Workflow: Telegram Post Aggregator

## Обзор

Этот workflow автоматически:
1. Мониторит указанные Telegram группы/каналы
2. Проверяет посты на дубликаты через хеширование
3. AI переписывает контент под твой формат
4. Удаляет все ссылки и следы источника
5. Публикует в твою группу

## Как работает дедупликация

### Проблема
Разные группы могут постить одно и то же (репосты, кросс-постинг).

### Решение: Hash-based deduplication

```
1. Для КАЖДОГО поста вычисляется уникальный hash:
   - Текст → SHA256(text)
   - Фото → MD5(photo_id)

2. Hash сохраняется в Redis с TTL 7 дней

3. При получении нового поста:
   - Вычисляем его hash
   - Проверяем: EXISTS post:{hash}?
   - Если ДА → пропускаем (дубль)
   - Если НЕТ → обрабатываем и сохраняем hash
```

### Почему это работает
- Два поста с одинаковым текстом из разных источников получат ОДИНАКОВЫЙ hash
- Даже если источник А репостнул от источника B, hash будет отличаться только если текст изменился
- TTL 7 дней = посты "забываются" через неделю (можно изменить)

## AI обработка контента

### Инструкция для AI (System Prompt)

```
Ты опытный редактор контента. Твоя задача:
1. Перепиши текст под формат нашей группы
2. Удали ВСЕ ссылки (URL, @mention групп/каналов)
3. Удали любые упоминания источника откуда пост
4. Сохрани суть и смысл поста
5. Если есть изображения - опиши их кратко для alt текста
6. Текст должен выглядеть органично, как будто написан для нашей группы

Формат вывода: ТОЛЬКО переработанный текст, БЕЗ пояснений.
```

### Что делает AI
- ✅ Переписывает текст своими словами
- ✅ Удаляет @username упоминания
- ✅ Удаляет URLs
- ✅ Удаляет "источник: @channel" и подобное
- ✅ Сохраняет смысл поста
- ✅ Делает текст "своим"

## Настройка

### 1. Создай Telegram Bot

```bash
# 1. Напиши @BotFather в Telegram
# 2. /newbot - создай нового бота
# 3. Получи API token

# Дай боту права читать в группах:
# 1. Добавь бота в SOURCE_GROUP как админа (или с правом читать сообщения)
# 2. Добавь бота в MY_GROUP как админа
```

### 2. Узнай Chat IDs

```bash
# Добавь @userinfobot в группу - он покажет chat_id
# Или используй @RawDataBot

# Формат: -100XXXXXXXXX (для супергрупп)
```

### 3. Создай Credentials в N8N

**Telegram API Credential:**
```json
{
  "accessToken": "YOUR_BOT_TOKEN"
}
```

**Redis Credential:**
```json
{
  "host": "localhost",
  "port": 6379,
  "password": ""
}
```

**OpenAI Credential:**
```json
{
  "apiKey": "sk-..."
}
```

### 4. Загрузи Workflow

```bash
# В n8n:
# 1. Settings → Import from File
# 2. Выбери n8n-telegram-aggregator-workflow.json
# 3. Настрой переменные (Workflow → Variables)
# 4. Подключи Credentials
```

### 5. Запуск

```bash
# Активируй workflow (toggle в n8n)
# Бот начнет слушать новые сообщения в SOURCE_CHAT_ID
```

## FAQ

**Q: Почему Redis, а не просто файл?**
A: Redis быстрый, поддерживает TTL (автоудаление), и n8n имеет нативную ноду для него.

**Q: Что если пост уже кто-то обработал, но мы прочитали раньше?**
A: Мы сохраняем hash ПЕРЕД отправкой, так что второй источник получит тот же hash и пост будет пропущен.

**Q: Можно ли добавить медиа?**
A: Да, в ноде "Send to My Group" есть параметры для фото/видео. Можно доработать AI Processor чтобы он возвращал и медиа.

**Q: Как изменить TTL хешей?**
A: В ноде "Save to Deduplication Store" параметр `TTL` = 604800 (секунд) = 7 дней.

**Q: Можно ли без Redis?**
A: Да, можно использовать SQLite или даже Google Sheets как хранилище хешей. Но Redis — самый быстрый вариант.
