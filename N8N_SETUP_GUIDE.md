# N8N: Автоматический сбор и перепостинг постов

## Что делает эта система

```
Источник (группа MAX/Тelegram)
       │
       ▼
┌──────────────────┐
│  Telegram Bot    │  ← Слушает новые посты
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  Дедупликация    │  ← Проверяет: этот пост уже был?
└────────┬─────────┘
         │
    новый? ──── да ──→ AI обработка ──→ Очистка ──→ Отправка в свою группу
         │
        нет (дубль) ──→ Пропуск
```

**Суть:** Бот читает посты из чужих групп → Если пост новый → AI переписывает → Убирает ссылки/следы → Постит в твою группу.

---

## Шаг 1: Создай Telegram Bot

1. Открой Telegram, напиши **@BotFather**
2. Отправь команду `/newbot`
3. Следуй инструкциям, сохрани **API Token** (выглядит как `123456789:ABCdefGHIjklMNOpqrSTUvwxyz`)

---

## Шаг 2: Добавь Bot в группы

Для КАЖДОЙ группы (источник и твоя):

1. Открой группу → Нажми на название → **Добавить участника**
2. Найди своего бота по имени
3. **Важно:** Сделай бота **Администратором** группы (иначе он не увидит сообщения)

---

## Шаг 3: Узнай ID групп

1. Добавь в группу бота **@userinfobot**
2. Бот покажет `chat_id` группы (например `-1001234567890`)
3. Повтори для всех групп-источников и твоей группы

---

## Шаг 4: Настрой Redis (для дедупликации)

**Зачем:** Redis хранит хеши уже обработанных постов, чтобы не постить дубли.

```bash
# Установка Redis (если нет)
sudo apt update && sudo apt install redis-server

# Запуск
redis-server --daemonize yes

# Проверка
redis-cli ping
# Должно ответить: PONG
```

---

## Шаг 5: Настрой N8N

### 5.1 Установи N8N

```bash
# Вариант 1: Docker
docker run -d --name n8n -p 5678:5678 n8nio/n8n

# Вариант 2: npm
npm install -g n8n
n8n start
```

Открой **http://localhost:5678**

### 5.2 Создай Credentials

**Telegram Bot API:**
- Settings → Credentials → New → Telegram Bot API
- Access Token: `твой_токен_бота`

**Redis:**
- Settings → Credentials → New → Redis
- Host: `localhost`
- Port: `6379`
- Password: (пусто)

**OpenAI (для AI обработки):**
- Settings → Credentials → New → OpenAI API
- API Key: `твой_openai_key`

### 5.3 Создай Workflow

1. Нажми **+** создать новый workflow
2. Импортируй файл `n8n-telegram-aggregator-workflow.json` (Workflow → Import from File)
3. Настрой переменные (Workflow → Variables):

| Переменная | Что писать | Пример |
|------------|------------|--------|
| `SOURCE_CHAT_ID` | ID группы-источника | `-1001234567890` |
| `MY_GROUP_ID` | ID твоей группы | `-1009876543210` |
| `TELEGRAM_CREDENTIALS` | Название credential | `telegram-bot` |
| `REDIS_CREDENTIALS` | Название credential | `redis` |
| `OPENAI_CREDENTIALS` | Название credential | `openai` |

## Как работает дедупликация (защита от дублей)

**Проблема:** Несколько источников могут постить одно и то же.

**Решение:**
```
Каждый пост получает "отпечаток" (hash):
- Текст → SHA256 hash
- Фото → MD5 hash

Когда пост приходит:
1. Вычисляем его hash
2. Спрашиваем Redis: "post:hash_поста" существует?
3. Если ДА → это дубль, пропускаем
4. Если НЕТ → обрабатываем и сохраняем hash
```

**Redis хранит хеши 7 дней**, потом自动删除 (TTL). Это значит:
- Если пост вернётся через неделю — он будет обработан снова
- Это нормально, т.к. за неделю контент мог измениться

## Как работает AI обработка

AI получает инструкцию:
```
Ты редактор. Твоя задача:
1. Перепиши текст под стиль нашей группы
2. Удали ВСЕ ссылки (URL, @упоминания)
3. Удали любые следы источника
4. Сохрани смысл поста
5. Выведи ТОЛЬКО готовый текст, БЕЗ пояснений
```

**Что удаляется:**
- Все URLs (http://..., https://...)
- Все @упоминания (@channel, @username)
- Все t.me ссылки
- Все "источник:", "взято из:" и подобное

## Как добавить несколько источников

**Вариант А: Несколько Telegram Trigger нод**

```
[Telegram Trigger: Группа 1] ─┐
[Telegram Trigger: Группа 2] ─┼─→ [Merge] → [Дедупликация] → ...
[Telegram Trigger: Группа N] ─┘
```

**Вариант Б: Schedule + Telegram API нода**

Используй ноду "Telegram API" с методом `getUpdates` и Schedule trigger для периодического опроса.

## Запуск и мониторинг

**Активация:**
- В n8n открой workflow → Toggle "Active"

**Проверка работы:**
- Settings → Execution History — все запуски с логами
- В Telegram bot добавь в группу, напиши тестовое сообщение
- Смотри в n8n: появится новый execution

**Ручной тест:**
1. Открой workflow → Нажми "Test workflow"
2. Отправь сообщение в группу-источник
3. Смотри как пост проходит через все ноды

## Возможные проблемы

| Проблема | Решение |
|----------|---------|
| Бот не видит сообщения | Сделай бота админом группы |
| Бот читает свои сообщения | Добавь проверку: `message.from.id !== bot_id` |
| Посты дублируются | Проверь Redis: `redis-cli KEYS post:*` |
| AI не отвечает | Проверь OpenAI credential и API key |
| Rate limit (429) | Telegram ограничивает ~30 msg/sec, добавь delay |
